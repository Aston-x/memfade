# 更新日志

## v0.1.0（2026-11-01）

首个版本。

* 双轴记忆模型：显著性不随时间变，强度随时间衰减；
* 四档淡化梯度：ACTIVE / FADING / GISTED / ARCHIVED；
* 会话严格隔离：作用域键用 MaiBot 的 `session_id`，跨会话共享需显式开启；
* 分层注入：事实层 + 回声层，另加常驻的「关于对方」画像块；
* 抽取复用宿主 `memory` 模型任务，向量复用宿主 `embedding` 任务——
  **不需要额外配置 API key**；
* 中文二元组检索 + 可选向量检索，加权打分；
* 近似重复自动合并，矛盾事实自动取代（保留证据链）；
* WebUI 面板：记忆总览、淡化档位分布、检索；
* 命令：`/记忆`、`/记忆 搜 <词>`、`/记忆 整理`、`/记住 <内容>`、`/忘掉 <片段>`；
* 工具：`remember_something`，让模型自己决定要不要记。
