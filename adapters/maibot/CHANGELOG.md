# 更新日志

## v0.4.0（2026-11-03）

修「记错」的一版。核心是**写入前的闸门**：每条候选记忆都回对话里找
**依据原话**（只找用户自己说的话），拿依据跟内容对账——
把「今天」写成「每天」、把「这次你用这种语气」写成「希望你用这种语气」，
这两类错法都会被降级成事件（信息还在，但不再常驻注入）。
临时状态（「暂时发不了」「被拦」）与临时情绪（「好累」「困」）直接不入库。

* 每条记忆存 `meta["quote"]`（依据原话），面板上看得见它是从哪句话来的；
* 抽取提示词加五条硬规矩：常态与这一次分清、条件不许丢、
  一次性的吩咐不是偏好、临时状态与情绪不记；
* 稳定事实的入库门槛 0.35 → 0.45；种类区间挪到落库时才夹；
* 新增 `/记忆 修正 <老内容> => <新内容>`，面板上也能改写/删除单条；
* 修掉面板「导入记忆」输入框名与 action 参数名对不上的老 bug；
* 运维工具新增 `edit_memory.py`（按清单批量修记忆，带自动备份）。

## v0.1.0（2026-11-01）

首个版本。

* 双轴记忆模型：显著性不随时间变，强度随时间衰减；
* 四档淡化梯度：ACTIVE / FADING / GISTED / ARCHIVED；
* 会话严格隔离：作用域键用 MaiBot 的 `session_id`，跨会话共享需显式开启；
* 分层注入：事实层 + 回声层，另加常驻的「关于对方」画像块；
* 抽取复用宿主 `memory` 模型任务，向量复用宿主 `embedding` 任务——
  **不需要额外配置 API key**；
* 中文二元组检索 + 可选向量检索，加权打分；
* 近似重复自动合并，矛盾事实自动取代（保留证据链）；
* WebUI 面板：记忆总览、淡化档位分布、检索；
* 命令：`/记忆`、`/记忆 搜 <词>`、`/记忆 整理`、`/记住 <内容>`、`/忘掉 <片段>`；
* 工具：`remember_something`，让模型自己决定要不要记。
